------------------ Сервлет (servlet):
в Java 		—это Java-класс, который расширяет функциональность веб-сервера. Он обрабатывает HTTP-запросы, взаимодействует с базами данных, вызывает другие веб-сервисы и формирует ответы клиенту. Сервлеты работают на серверной стороне и могут генерировать динамический контент. Они позволяют: 
	-создавать динамические страницы, на которые контент подгружается «на лету»;
	-запрашивать информацию у базы данных и получать ответ;
	-собирать сведения от пользователей через формы для записей;
	-выводить сообщения в ответ на запрос и делать многое другое.
Для создания сервлетов используются пакеты javax.servlet и javax.servlet.http. 
Разработчик создаёт класс сервлета в коде и описывает, что он должен делать при получении того или иного запроса. После этого код сервлета загружается на сервер. Там специальное ПО создаёт экземпляр сервлета, и тот начинает обрабатывать запросы. Если сервлет перестаёт быть нужен, это же ПО удаляет работающий экземпляр. Некоторые особенности работы сервлетов:
	-Могут обрабатывать различные типы HTTP-запросов (GET, POST, PUT и т. д.).
	-Сохраняют состояние между запросами через сессии.
	-Имеют доступ ко всей мощи Java API.

================== Основное отличие веб-сервиса от обычного веб-приложения заключается в том, что веб-сервис предназначен для взаимодействия с другими системами, а веб-приложение — для использования пользователем. 
------------------ Web-Application:
— это программное приложение, которое запускается в веб-браузере и доступно пользователям через интернет. Его цель — предоставить пользователю определённую функциональность или сервис, который позволяет решать задачи или упрощает выполнение задачи. Некоторые особенности веб-приложений:
	-Интерактивный интерфейс с кнопками, формами и другими элементами для взаимодействия с пользователем.
	-Возможность хранить и получать данные с сервера или базы данных, что позволяет пользователям сохранять предпочтения и другую информацию для будущего использования.
	-Доступность — веб-приложение может быть запущено на любом устройстве с доступом к интернету.
	-Масштабируемость — способность приложения эффективно работать при большом числе пользователей.
	-Обновляемость — возможность внесения изменений и обновления приложения без необходимости переустановки на устройствах пользователей.
Примеры веб-приложений: интернет-магазины, социальные сети, онлайн-банкинг, системы управления проектами. 
------------------ Web Service:
Веб-сервис — это программное приложение или компонент, который доступен через интернет и взаимодействует с другими системами для выполнения конкретной задачи. В отличие от обычных веб-приложений, веб-сервисы могут не взаимодействовать напрямую с конечным пользователем. Главная цель веб-сервисов — упростить интеграцию между различными системами и платформами. Они могут обмениваться данными, выполнять команды и помогать автоматизировать рутинные процессы. Некоторые особенности веб-сервисов:
	Модульность — веб-сервисы зачастую создаются как отдельные модули, которые можно легко интегрировать в различные системы.
	Доступность через интернет — веб-сервисы работают через интернет, что делает их доступными из любой точки мира.
	Интероперабельность — эти сервисы могут взаимодействовать с различными платформами, независимо от их архитектуры или используемых технологий.
Примеры веб-сервисов: 
Amazon Web Services (AWS) 	— облачная платформа, предоставляющая инфраструктуру и услуги для разработки и хостинга приложений, 
Яндекс Диск 			— облачный сервис для хранения и обмена файлами. 
Важно: веб-разработка часто объединяет оба этих формата — например, интернет-магазин использует сайт для покупателей и веб-сервис для интеграции с оплатой, доставкой, складом и CRM.
