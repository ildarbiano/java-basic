===================== Функциональное программирование в Java:
это парадигма декларативного программирования, в которой программы создаются путём последовательного применения функций, а не инструкций. Каждая функция принимает входное значение и возвращает согласующееся с ним выходное значение, не изменяясь и не подвергаясь воздействию со стороны состояния программы. 
Язык Java создавался как объектно-ориентированный, но с 8-й версии (2014 г.) к объектно-ориентированной модели добавилась функциональная. 
--------------------- Некоторые концепции функционального программирования в Java:
Функции 			как объект первого класса. Функция может быть передана в виде аргумента в другую функцию и/или возвращена другой функцией как значение. 
Чистые функции			не создают побочных эффектов и всегда производят одинаковый вывод при получении одинакового ввода. 
Иммутабельность данных		состояние данных не изменяется, что позволяет сделать результаты выполнения программы более предсказуемыми и достичь ссылочной прозрачности. 
Композиция функций		функции могут быть объединены в цепочку, что позволяет применять серию преобразований к данным последовательно. 
Функции высшего порядка		принимают в виде аргументов и/или возвращают как значения другие функции. Такие функции представлены, например, в Stream API, CompletableFuture, Optional. 
--------------------- Инструменты:
Для реализации функционального программирования в Java в Java 8 представлен пакет java.util.function с готовыми функциональными интерфейсами для наиболее распространённых случаев. Например: 
Function<T, R> 		— принимает аргумент типа T и возвращает результат типа R;
Predicate<T> 		— принимает аргумент и возвращает логическое значение;
Consumer<T> 		— принимает аргумент и ничего не возвращает (void);
Supplier<T> 		— не принимает аргументов, но возвращает значение типа T;
BinaryOperator<T> 	— принимает два аргумента одного типа и возвращает значение того же типа.
--------------------- Лямбда-выражения:
— анонимные функции, которые можно сохранять в переменных, передавать как аргументы и возвращать из методов, для создания лаконичного кода в функциональном стиле используются.
Некоторые примеры использования функционального программирования в Java:
--- Фильтрация данных с помощью Predicate, который принимает аргумент и возвращает логическое значение:
Например, список строк 	names = List.of("Alice", "Bob", "Charlie"); 
			names.remove If(name -> name.startsWith("B")); 
			System.out.println(names);
			вывод: [Alice, Charlie].
--- Преобразование данных с помощью Function, который принимает аргумент типа T и возвращает результат типа R:
Например, список строк 	names = List.of("Alice", "Bob", "Charlie"); 
			List<Integer> nameLengths = names.stream() .map(String::length) .toList(); 
			System.out.println(nameLengths);
			вывод: [5, 3, 7].
